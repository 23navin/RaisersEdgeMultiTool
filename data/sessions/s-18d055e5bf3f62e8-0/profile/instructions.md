# Gift Activity Report

A real-time operational report of recent gifts and the constituents who made
them. Pick a gift date range, press **Refresh** to pull live data from RE NXT,
and review the results. You can then create a saved query in RE from the
constituents shown.

---

<!-- label: gifts_table -->
## Constituents & Gifts

Each row is a gift within the selected date range, joined to its constituent.
Sort by any column. Use **Create Query in RE** to save these gifts as a query
you can open inside the RE CRM.
